# 家电财报有据 · 第三课方向 A（问答知识库）

12 家**家用电器**行业 A 股上市公司 **2025 年年度报告全文**（取自交易所指定的信息披露网站
[巨潮资讯网](http://www.cninfo.com.cn/)），做成一个**能提问、答案带出处**的问答知识库：
本地中文向量 + BM25 混合检索（RRF 融合），答案里的每个数字都能点回到具体公司、章节、
PDF 页码和官方原文链接。

只完成方向 A（把知识放进库里检索），没有训练或微调模型。

## 语料

公司（12 家，覆盖白电、黑电、厨电、小家电）：

美的集团(000333)、格力电器(000651)、海尔智家(600690)、海信家电(000921)、TCL智家(002668)、
长虹美菱(000521)、老板电器(002508)、万和电气(002543)、火星人(300894)、苏泊尔(002032)、
九阳股份(002242)、莱克电气(603355)

- **报告期口径**：只使用 **2025 年年度报告**正式版（排除摘要、英文版、更正版）。不混入半年报，
  也不混入其他年份。
- **页数**：2,544 页；检出表格区域 3,661 个；生成知识块 **18,671** 个（正文 11,737 + 表格 6,934）。
- **`page` 一律是 PDF 物理页码**（从 1 开始），引用链接里的 `#page=` 用的也是它。

年报 PDF 本身不进仓库（体积大且有版权），用 `download_reports.py` 一条命令即可重新下载并校验 SHA-256。

## 运行

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. 下载 12 份年报全文（约 27 MB）
python download_reports.py

# 2. 抽取正文与表格
python extract_reports.py

# 3. 切块（正文约 400 字/块重叠 60 字；表格按行切、每块重复表头）
python build_chunks.py

# 4. 建索引（向量 + BM25）
python build_index.py

# 5. 起问答页面 → http://127.0.0.1:8765
python app.py
```

生成答案需要一个 OpenAI 兼容的大模型接口，放在 `.env`（已在 `.gitignore` 中）：

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
DASHSCOPE_API_KEY=sk-...        # 向量化用（阿里云百炼 text-embedding-v4）
```

**检索本身不依赖外部服务**：BM25 完全本地。向量后端可切换——如果本地 ONNX 模型
`models/onnx-bge-small-zh/model.onnx` 存在就优先用**本地 BGE**（bge-small-zh-v1.5，512 维，完全离线，
见 `embedding.py`），否则回退到阿里云百炼 `text-embedding-v4`（1024 维）。
页面上可以随时切换「混合 / 纯向量 / 纯关键词」，用来观察两类召回各自的短板。

## 方法

1. **抽取**（`extract_reports.py`）
   PyMuPDF 按页读正文，用内建的表格识别拿到表格区域的原始二维单元格矩阵；
   同时记录每一行的字号与加粗，供章节归属用。空单元格保留为空串，不做任何数值猜测。

2. **切块**（`build_chunks.py`）
   正文目标约 400 字、相邻块重叠 60 字，优先在句末断开；
   表格**按数据行切分**，每组都重复该表表头（含多级表头），保证单独一块也能看懂列的含义。
   每块携带：公司、证券代码、报告标题、章节、PDF 页码、官方链接（含 `#page=`）、块类型、稳定 ID。

3. **向量**（`embedding.py`）
   中文语义向量 `BAAI/bge-small-zh-v1.5`（本地 ONNX，512 维，CLS pooling + L2 归一化，
   检索问题加 BGE 官方推荐指令前缀、文档不加）；本地模型不可用时回退到阿里云百炼
   `text-embedding-v4`（1024 维）。余弦相似度用 NumPy 精确检索。

4. **关键词**（`build_index.py`）
   jieba 分词（把 12 家公司全称和「归母净利润」「经营活动产生的现金流量净额」等财报术语加进自定义词典），
   BM25 自己实现，`k1=1.5、b=0.75`。

5. **混合召回**（`rag.py`）
   向量、BM25 各取前 60 名，按 `1/(60+rank)` 相加做 RRF 融合，取前 6 块作为证据。
   问题里点明公司时按公司过滤。

6. **回答**
   把召回块连同「公司 / 章节 / PDF 页码 / 类型」一起交给大模型，要求：
   只用给定资料作答、**每个数字后面必须带 `[n]` 引用**、资料里没有就明确说「资料中未找到」。
   页面把 `[n]` 渲染成可点的上标，点开就是原文块和官方 PDF 链接。

## 评测协议

- 10 道题在**跑之前冻结**（`evaluation/questions.json`），参考答案逐条对照年报 PDF 原文人工核对，
  并标注了来源页码；之后不再修改题目或参考答案。
- 题型覆盖：单公司数字、多列表头（分季度）、跨表比率、口语化提问、经营解释、
  研发投入、**2 道跨公司全景题**、**1 道库外时点题**（语料只有 2025 年报，问 2026 半年报应当明确拒答）。
- 每题同时跑「纯向量」和「纯关键词」两条单路召回，记录混合检索里的每一块在两个单路召回中排名第几，
  用来定位是哪一路掉了链子。
- 运行结果原样保留在 `evaluation/runs/`，**答错、翻车也照实记录**，不用漂亮截图替代失败记录。
- 结论写在 `deliverables/一页结论.pdf`，并在 `evaluation/逐题评测.md` 里逐题给出判断与错误归因。

## 来源与边界

- 年报全文：[巨潮资讯网](https://www.cninfo.com.cn/)，逐份链接与校验值见 `data/sources.json`。
- 向量模型：[BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5)；
  本地无法下载模型时回退阿里云百炼 text-embedding-v4。
- 页面只监听本机回环地址；模型输出与原文都做 HTML 转义后渲染。
- 仓库里**不出现任何 API key**：key 只放 `.env`，`.gitignore` 已排除；年报 PDF 也不进仓库，只留下载脚本。
- 未全面核验每张表格：无边框表格、复杂合并单元格和跨页续表仍可能抽取不完整；
  非表格区保留全文文本供检索，但这不等于所有表格都被完美结构化。
